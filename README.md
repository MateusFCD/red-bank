💰 **Gerenciador Financeiro**
<br>Aplicação mobile para gerenciamento de finanças pessoais, desenvolvida com React Native + Expo e integrada ao Firebase.

✨**Funcionalidades**
<br>🔐 Login vinculado a conta Google
<br>📊 Dashboard com gráficos e análises financeiras
<br>💰 Controle de entradas e gastos
<br>🔎 Filtros de transações
<br>➕ Adicionar transações
<br>✏️ Editar transações
<br>✅ Validação de campos
<br>🧾 Upload de recibos para o Firebase

📦 **Instalação**
<br>Clone o repositório
<br>Instale as dependências:
npm install
<br>Execute o projeto:
npx expo start
<br>Depois, abra pelo Expo Go ou em um emulador Android/iOS.
