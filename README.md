💰 **Gerenciador Financeiro**

Aplicação mobile para gerenciamento de finanças pessoais, desenvolvida com React Native + Expo e integrada ao Firebase.

✨**Funcionalidades**
🔐 Login vinculado a conta Google
📊 Dashboard com gráficos e análises financeiras
💰 Controle de entradas e gastos
🔎 Filtros de transações
➕ Adicionar transações
✏️ Editar transações
✅ Validação de campos
🧾 Upload de recibos para o Firebase

📦 **Instalação**

Clone o repositório

Instale as dependências:
npm install

Execute o projeto:
npx expo start

Depois, abra pelo Expo Go ou em um emulador Android/iOS.
